# driverless-ml-dev

Machine Learning-related scripts and architecture for Carnegie Mellon Racing

## Datatype conventions:

- IDs are always in python datatypes: lists, dictionaries, etc
- Point (x,y coordinates) are always numpy datatypes: cone_map is a nx2 numpy array indexed by the IDs
- Radians are the convention for angular values
